# 『잡아함경 쉬운 완전읽기』 제26권
## 수행의 힘은 어떻게 자라는가 — 오근·오력·참괴·여래십력·오개·칠각지·조건 있는 청정

> **범위:** 『잡아함경』 제26권, 제642경~제711경  
> **원문 기준:** CBETA 2026.R1, T02, no.99 『雜阿含經』 卷第二十六  
> **수록 경수:** **70경**  
> **읽기 방식:** 제26권은 반복경이 많다. 하나씩 따로 외우기보다 **“수행의 능력이 어떻게 근(根)에서 힘(力)으로 자라고, 무엇이 그 힘을 약화시키며, 무엇이 깨달음의 요소를 키우는가”**라는 큰 구조로 읽는 편이 좋다. 제642~660경은 **세 근과 오근**, 제661~683경은 **여러 수행의 힘과 윤리적 자기점검**, 제684~703경은 **아라한과 여래의 차이·여래의 여러 지혜력**, 제704~711경은 **오개와 칠각지·조건 있는 번뇌와 청정**을 다룬다.

---

# 한 문장 핵심

『잡아함경』 제26권은 이렇게 정리할 수 있습니다.

# **신뢰·정진·마음챙김·삼매·지혜는 따로 놀지 않고 서로를 받쳐 주는 ‘근’과 ‘힘’으로 자라며, 그 가운데 지혜는 사성제를 사실대로 보고 다른 수행 요소를 바른 방향으로 붙드는 들보 역할을 한다. 반대로 탐욕·성냄·졸림·들뜸과 후회·의심이라는 오개는 지혜를 약하게 하고, 바른 사유와 정법 청취는 칠각지를 자라게 한다. 결국 번뇌도 청정도 원인 없이 생기는 것이 아니라 조건에 따라 생기고 조건에 따라 사라진다.**

제26권의 흐름을 먼저 보면 다음과 같습니다.

# **신뢰**
→ **정진**
→ **마음챙김**
→ **삼매**
→ **지혜**

이 다섯이,

# **근(根)**
에서
# **힘(力)**

으로 자랍니다.

그리고,

# **오개**
→ **마음을 덮음**
→ **지혜 약화**
→ **퇴보**

반대로,

# **바른 사유·정법 청취**
→ **칠각지**
→ **지혜 성장**
→ **열반 방향**

입니다.

# 제1경군 — 제642~660경
## 오근 — 신뢰·정진·마음챙김·삼매·지혜는 어떻게 하나의 체계가 되는가

---

# 제642경 — 세 가지 ‘근’: 배우는 단계에서 완성까지

제642경은 다섯 근보다 먼저 세 근을 말합니다.

### 未知當知根
# **아직 알지 못한 것을 알아야 한다는 근**

### 知根
# **알아 가는 근**

### 無知根
# **더 이상 알아야 할 것이 남지 않은 완성의 근**

으로 이해할 수 있습니다.

게송은,

# **학인의 단계에서 바른 길을 따라 정진하고**
# **마음을 잘 보호하며**
# **생이 다했음을 직접 알고**
# **흔들리지 않는 마음해탈에 이르는 과정**

을 노래합니다.

---

## [주의] `無知根` = 무지의 근?

아닙니다.

여기의 `無知根`을,

# **어리석음·무명이라는 의미의 ‘무지’**

로 읽으면 문맥이 완전히 뒤집힙니다.

이 세 근은,

# **알아야 함 → 알아 감 → 완전히 알아 더 알 일이 없음**

이라는 수행 단계입니다.

---

# 제643경 — 오근의 기본 목록

부처님은 다섯 근을 듭니다.

# **信根 — 신뢰의 근**
# **精進根 — 정진의 근**
# **念根 — 마음챙김의 근**
# **定根 — 삼매의 근**
# **慧根 — 지혜의 근**

입니다.

여기서 `根`은 단순한 기관이 아니라,

# **수행을 지탱하고 자라게 하는 기본 능력**

으로 이해하면 쉽습니다.

---

# 제644경 — 오근을 사실대로 보면 수다원

오근을 사실대로 관찰하면,

# **신견**
# **계취**
# **의심**

이라는 세 결박을 끊고,

# **수다원**

이 된다고 합니다.

또 악처에 떨어지지 않고,
마침내 괴로움의 끝으로 향한다고 전합니다.

[전승]

수다원의 일곱 번 이내 재생 등은 초기불교의 성자 단계 전승입니다.

---

# 제645경 — 오근을 사실대로 관찰해 누를 다하면 아라한

제645경은 더 높은 성취를 말합니다.

# **오근을 사실대로 관찰해**
# **여러 누가 일어나지 않고**
# **마음이 이욕으로 해탈하면**

아라한이라고 합니다.

즉 오근은,

# **입문자의 성격 장점 목록**

이 아니라 해탈까지 이어지는 수행 체계입니다.

---

# 제646경 — 오근은 37도품과 사성제를 한 줄로 묶는다

제646경은 오근 하나하나를 다른 수행군과 연결합니다.

# **신근**
= **사불괴정**

# **정진근**
= **사정단**

# **념근**
= **사념처**

# **정근**
= **사선**

# **혜근**
= **사성제**

입니다.

이 한 경은 매우 중요합니다.

초기불교의 수행 목록들이 서로 떨어진 암기표가 아니라,

# **신뢰 → 정진 → 마음챙김 → 삼매 → 사성제의 지혜**

라는 하나의 구조로 묶인다는 것을 보여 줍니다.

---

# 제647경 — 오근의 구체적 정의

제647경은 제646경을 풀어 씁니다.

## 신근
여래에 대해,

# **깊고 뿌리 깊은 청정한 신뢰**

를 세워
다른 사람이나 세상의 압력에 쉽게 무너지지 않는 것입니다.

---

## 정진근
네 가지 바른 노력입니다.

# **이미 생긴 악은 끊고**
# **아직 생기지 않은 악은 막고**
# **아직 생기지 않은 선은 일으키고**
# **이미 생긴 선은 유지·증장합니다.**

---

## 념근
몸·느낌·마음·법을,

# **정진**
# **바른 마음챙김**
# **분명한 앎**

으로 관찰해
세상의 탐욕과 근심을 조복합니다.

---

## 정근
욕·악불선법을 떠나,

# **초선에서 제4선까지**

닦는 것입니다.

---

## 혜근
# **고**
# **집**
# **멸**
# **도**

의 사성제를 사실대로 아는 것입니다.

---

# 제648~649경 — 같은 오근, 다른 성취

제648경은 오근을 사실대로 관찰해 **세 결박을 끊은 수다원**을,
제649경은 **누를 다한 아라한**을 말합니다.

같은 수행 요소라도,

# **얼마나 깊이 성숙했는가**

에 따라 결과가 달라집니다.

---

# 제650경 — 오근에도 사성제의 방식이 적용된다

부처님은 말합니다.

신근에 대해,

# **신근 자체**
# **신근의 발생**
# **신근의 소멸**
# **신근의 소멸로 가는 길**

을 사실대로 알지 못했다면
정각을 이루지 못했을 것이라고 합니다.

정진·념·정·혜도 같습니다.

---

## 사성제는 ‘고’에만 쓰는 틀이 아니다

제650경은 사성제식 구조가,

# **수행 요소 자체를 분석하는 방식**

으로도 쓰일 수 있음을 보여 줍니다.

즉,

# **무엇이 있는가**
# **어떻게 생기는가**
# **어떻게 사라지는가**
# **어떻게 사라지게 하는가**

를 보는 틀입니다.

---

# 제651경 — 오근도 맛·위험·벗어남을 본다

제651경은 각 근에 대해,

# **발생**
# **소멸**
# **맛**
# **위험**
# **벗어남**

을 사실대로 알아야 한다고 합니다.

이 구조는 제17권의 느낌,
제308경의 감각 대상 등에서 반복되었습니다.

# **좋다고 붙잡기만 하지 않고**
# **그것의 이익과 한계, 놓아야 할 지점까지 본다**

는 방식입니다.

---

# 제652경 — 오근의 강약과 네 성과

오근이 매우 날카롭고 충만하면,

# **아라한**

에 이르고,
그보다 약하면,

# **아나함**
# **사다함**
# **수다원**

등 서로 다른 성취에 이른다고 합니다.

그리고 중요한 문장이 나옵니다.

# **오근은 헛되거나 결과 없는 것이 아니다.**

반대로 이 근들이 전혀 없으면,
경은 아직 범부의 범주에 있다고 말합니다.

---

# 제653경 — 오근의 정도에 따른 더 세밀한 수행자 구분

제653경은 오근의 강약에 따라,

### 구분해탈
### 신증
### 견도
### 신해탈
### 일종
### 사다함
### 가가
### 칠유
### 법행
### 신행

같은 여러 수행자 유형을 나열합니다.

[주의]

초보 단계에서는 이 열 개의 명칭을 모두 외울 필요가 없습니다.

이 경의 핵심은,

# **오근의 성숙도가 수행자의 성취 수준과 연결된다**

는 것입니다.

---

# 제654경 — 지혜는 건물의 들보와 같다

제26권의 핵심 비유 가운데 하나입니다.

[비유]

건물의 여러 재료는,

# **가장 중요한 들보에 의지해 서로 지탱됩니다.**

마찬가지로 다섯 근 가운데,

# **慧根 — 지혜의 근이 우두머리**

가 되어 다른 근들을 붙든다고 합니다.

---

## 왜 신뢰보다 지혜가 우두머리인가

신뢰가 있어도,
무엇을 믿어야 하고 무엇을 버려야 하는지 모르면 방향을 잃을 수 있습니다.

정진도,
잘못된 방향으로 열심히 갈 수 있습니다.

마음챙김과 삼매도,
무엇을 사실대로 알아야 하는지 없으면 해탈로 가지 않을 수 있습니다.

그래서,

# **사성제를 아는 지혜가 다른 근들의 방향을 잡습니다.**

---

# 제655~658경 — 다시 반복되는 ‘혜근이 들보’

제655경은 다시,

# **신근=불괴정**
# **정진근=사정단**
# **념근=사념처**
# **정근=사선**
# **혜근=사성제**

라고 하고,
모든 공덕은 지혜를 우두머리로 삼는다고 합니다.

제656경은 더 나아가,

# **지혜가 갖추어져야 신뢰·정진·념·정도**
# **이욕·무욕·멸·놓아 버림의 방향**

으로 바르게 닦인다고 합니다.

제657경은 무시무시한 생사의 흐름을 보며,

# **무명과 갈애가 있기에 생사가 있고**
# **그 원인이 완전히 다하면 생사도 없다**

고 말합니다.

그리고 열반을,

# **괴로움의 소멸**
# **괴로움의 쉼**
# **청량함**

으로 설명합니다.

제658경은 다시 오근 전체의 정의와
지혜의 우두머리 역할을 압축합니다.

---

# 제659경 — `菩提心`이라는 표현을 어떻게 읽을 것인가

제659경에는 눈에 띄는 표현이 나옵니다.

# **「於如來發菩提心」**
# **「初發菩提心」**

이라는 문구입니다.

신·정진·념·정·혜의 다섯 근을,
여래를 향해 보리심을 일으킨 것과 연결합니다.

---

## [전승·주의] 바로 대승의 보리심 체계로 읽어야 하는가

그렇게 단정하지 않습니다.

현존 한역 제659경에 **`菩提心`이라는 말이 실제로 있는 것**은 분명합니다.

그러나 이 한 문구를 근거로,

# **후대 대승불교의 보살서원·보리심 전체 체계가 이 경에 그대로 들어 있다**

고 말하지 않습니다.

이 경군의 직접 중심은 여전히,

# **오근**
# **이욕·멸·놓아 버림**
# **괴로움의 끝**

입니다.

---

# 제660경 — 오근을 많이 닦으면 과거·현재·미래의 괴로움이 끊어진다

제660경은 오근을,

# **많이 닦고 반복해 닦으면**
# **과거·현재·미래의 모든 괴로움이 끊어진다**

고 말합니다.

현존 한역은 이어,

### 괴로움의 끝
### 괴로움의 소멸
### 괴로움의 흐름을 건넘
### 결박에서 해방
### 모든 누의 소멸

도 같은 방식이라고 압축합니다.

---

# 제2경군 — 제661~683경
## ‘힘’이란 무엇인가 — 결과를 헤아리는 힘·수행력·사섭·참괴

---

# 제661경 — 두 힘: 헤아림의 힘과 수행의 힘

부처님은 두 가지 힘을 듭니다.

# **數力 — 헤아림의 힘**
# **修力 — 수행의 힘**

입니다.

---

## 헤아림의 힘

성스러운 제자는 조용한 곳에서 생각합니다.

> **“몸으로 악행을 하면 지금도 후회하고, 다른 사람과 스승에게도 책망받고, 나쁜 평판이 생기며, 죽은 뒤 악처의 과보도 받을 수 있다.”**

말과 마음의 악행도 같습니다.

그래서,

# **악행을 끊고 선행을 닦습니다.**

[주의]

이것은,

# **두려움만으로 사람을 통제하는 윤리**

로 축소할 필요가 없습니다.

핵심은,

# **행동의 결과를 미리 헤아려 충동을 멈추는 능력**

입니다.

---

# 제662경 — 헤아림에서 탐·진·치의 절제와 소멸로

제662경은 이 자기점검이 성숙하면,

# **탐욕·성냄·어리석음이 줄거나 다하는 방향**

으로 간다고 합니다.

즉 윤리적 숙고는 단순한 사회적 체면 관리가 아니라,
번뇌의 약화와 연결됩니다.

---

# 제663경 — 수행의 힘은 무엇을 닦는가

제663경은 수행의 힘을,

# **사념처를 닦는 것**

이라고 설명합니다.

그리고 같은 방식으로,

### 사정단
### 사여의족
### 오근
### 오력
### 칠각지
### 팔정도
### 지와 관

등을 닦는 것도 수행력이라고 압축합니다.

## 핵심 차이 — 길을 먼저 스스로 발견하고 남에게 가르친다

# **그 법과 길을 따라 수행해 해탈**

합니다.

### 출가자의 인내
### 다문한 사람의 사유

입니다.

[주의]

여기에도 제692~693경과 같은 고대 사회의 유형화와 성별 고정관념이 들어 있습니다.

# **모든 사람의 본성을 규정하는 보편 심리학**

으로 읽지 않습니다.

# 제701~703경 — 다시 여래십력, 그리고 가르침의 자신감

제701경은 여래십력을 다시 압축합니다.

제702경은,

# **누가 물으면 여래는 자신이 실제로 알고 본 것을 근거로 답한다**

는 형식으로 반복합니다.

제703경은 한 걸음 더 갑니다.

누군가,

# **아첨하지 않고**
# **속이지 않고**
# **정직한 마음으로**

가르침을 받으러 오면,
부처님은 그에게 법을 설하고 지도합니다.

그리고,

# **실제를 실제로**
# **실제가 아닌 것을 실제가 아닌 것으로**
# **위인 것을 위로**
# **그보다 위가 없는 것을 그보다 위가 없는 것으로**

알게 한다고 말합니다.

---

## 바른 길과 그릇된 길을 구분한다

제703경의 마지막은,

# **바른 길은 확정적인 길**
# **그릇된 길은 그렇지 않은 길**

이라고 말합니다.

즉 부처님의 ‘힘’은,
괴력을 자랑하는 능력보다,

# **무엇이 해탈로 가고 무엇이 그렇지 않은지를 정확히 알고 가르치는 능력**

에 중심이 있습니다.

에서 구분됩니다.

# 제4경군 — 제704~711경

# 제704경 — 바르지 않은 사유와 바른 사유

제704경은 조건 관계를 아주 명확히 보여 줍니다.

# **바르지 않은 사유**
를 하면,

### 아직 생기지 않은 탐욕개가 생기고
### 이미 생긴 탐욕개는 더 커집니다.

성냄·졸림·들뜸과 후회·의심도 같습니다.

동시에,

# **아직 생기지 않은 칠각지는 생기지 않고**
# **이미 생긴 칠각지는 약해집니다.**

---

## 반대로 바른 사유를 하면

# **오개는 생기지 않거나 사라지고**
# **칠각지는 생기고 자랍니다.**

칠각지는,

# **념**
# **택법**
# **정진**
# **의**
# **희**
# **정**
# **사**

입니다.

---

# 제705경 — 오개는 퇴법, 칠각지는 불퇴법

제705경은 아주 간단합니다.

# **탐욕·성냄·졸림·들뜸과 후회·의심**
= **퇴보시키는 법**

# **칠각지**
= **물러나지 않게 하는 법**

입니다.

---

# 제706경 — 오개는 어둠, 칠각지는 큰 밝음

오개는,

# **어둠을 만들고**
# **눈을 없애고**
# **지혜를 약하게 하며**
# **정각과 열반으로 향하지 못하게 합니다.**

반대로 칠각지는,

# **큰 밝음**
# **눈**
# **지혜의 성장**
# **정각**
# **열반 방향**

이라고 합니다.

---

# 제707경 — 마음을 덮는 것과 마음을 밝히는 것

제707경도 같은 대비를 반복합니다.

오개는,

# **마음을 덮고**
# **괴롭히고**
# **지혜를 약하게 합니다.**

칠각지는,

# **마음을 덮지 않고**
# **지혜를 자라게 하며**
# **열반으로 향하게 합니다.**

게송은,

# **념각지를 맨 앞에 두고**
# **택법·정진·의·희·정·사**

를 차례로 듭니다.

---

# 제708경 — 감각수호를 잃으면 작은 씨앗이 큰 나무가 된다

출가한 수행자가 마을에 걸식하러 들어갑니다.

그런데,

# **몸과 감각문을 잘 지키지 않고**
# **마음챙김을 거두지 않은 채**
# **젊고 아름다운 여성을 보고 욕탐을 일으킵니다.**

그 욕망이 커져
결국 수행을 그만두고 재가로 돌아간다는 장면이 나옵니다.

---

## [주의] 여성이 수행자를 타락시킨다는 이야기인가

아닙니다.

경이 직접 문제 삼는 것은,

# **수행자가 자기 감각문을 지키지 않고**
# **바르지 않게 사유하며**
# **마음이 대상을 붙잡아 욕탐을 키운 것**

입니다.

원인을 여성 존재 자체에 돌리지 않습니다.

---

## 다섯 큰 나무 비유

아주 작은 씨앗이 자라
큰 나무가 되면
주변의 작은 나무를 가리고 시들게 할 수 있습니다.

마찬가지로,

# **작은 탐욕의 씨앗**
# **작은 졸림**
# **작은 들뜸과 후회**
# **작은 의심**

도 방치하면 커져
선한 마음을 덮습니다.

경문은 다섯 오개를 이런 ‘마음의 큰 나무’에 비유합니다.

---

## 칠각지를 많이 닦으면 불퇴전

오개가 커지는 반대 방향으로,

# **칠각지를 반복해 닦으면**
# **물러나지 않는 방향으로 전환됩니다.**

---

# 제709경 — 정법을 한마음으로 들으면

비구가,

# **마음을 한곳에 모아 정법을 귀 기울여 들으면**

오개를 끊고,
칠각지를 닦아
충만하게 할 수 있다고 합니다.

즉,

# **듣는 것 자체도 수행의 조건**

입니다.

제565경의,

# **법을 듣고 암송하고 설명하고 사유해 정견을 키운다**

는 가르침과 연결됩니다.

---

# 제710경 — 청정한 신뢰와 법 청취에서 마음해탈·혜해탈로

성스러운 제자가,

# **청정한 신뢰로**
# **정성을 다해 법을 들으면**

오개를 끊고 칠각지를 닦아 충만하게 합니다.

그리고 두 가지를 구분합니다.

# **탐욕에 물든 마음**
은 즐거움과 자유를 얻지 못하고,

# **무명에 물든 지혜**
는 청정하지 못합니다.

그래서,

# **탐욕에서 떠나면 마음해탈**
# **무명에서 떠나면 혜해탈**

이라고 합니다.

마침내,

# **갈애의 결박을 끊고**
# **만을 꿰뚫어**
# **괴로움의 끝**

에 이른다고 합니다.

---

# 제711경 — 번뇌와 청정은 ‘원인 없이’ 생기지 않는다

무외 왕자가 부처님께 묻습니다.

일부 사문·바라문은,

> **“중생이 번뇌하는 데 원인과 조건이 없고, 중생이 청정해지는 데도 원인과 조건이 없다.”**

고 주장합니다.

부처님은 강하게 반박합니다.

# **번뇌에도 원인·조건이 있고**
# **청정에도 원인·조건이 있다.**

---

# 무엇이 번뇌의 조건인가

부처님은,

### 남의 재물에 대한 탐욕
### 다른 사람을 향한 성냄과 해칠 생각
### 졸림과 게으름
### 들뜬 마음
### 과거·현재·미래에 대한 의심

등을 듭니다.

즉 다시,

# **오개**

가 중심에 있습니다.

무외 왕자는,

> **“한 가지 덮개만 있어도 마음을 괴롭히기에 충분한데 하물며 전부라면 어떻겠습니까?”**

라고 합니다.

---

# 무엇이 청정의 조건인가 — 칠각지의 순서

부처님은 칠각지가 자라는 과정을 설명합니다.

# **1. 념각지**
기억하고 마음에 붙듭니다.

↓

# **2. 택법각지**
법을 선택하고 분별해 사유합니다.

↓

# **3. 정진각지**
바르게 분별한 뒤 정진합니다.

↓

# **4. 희각지**
정진하면서 기쁨이 생깁니다.

↓

# **5. 의각지**
몸과 마음이 가라앉고 편안해집니다.

↓

# **6. 정각지**
편안함을 바탕으로 마음이 안정됩니다.

↓

# **7. 사각지**
탐욕과 근심이 가라앉아 평형이 자랍니다.

---

## 칠각지는 단순한 일곱 단어가 아니다

제711경은 칠각지를,

# **앞의 조건이 뒤의 요소를 자라게 하는 수행의 흐름**

으로 보여 줍니다.

그래서 무외 왕자는,

# **한 요소만 충만해도 청정에 도움이 되는데**
# **일곱이 모두 갖추어지면 얼마나 크겠는가**

라고 찬탄합니다.

그는 이 가르침을 듣자
산을 올라오며 느꼈던 피로가 사라졌다고 말합니다.

경 이름도,

# **覺支經 — 각지경**

이라고 합니다.

# **고대 사회의 성별 고정관념이 반영된 유형 목록**

으로 구분합니다.

현존 원문을 숨기지 않되,
현대의 보편적 인간 본성론으로 만들지 않습니다.

---

## “제708경은 여성을 보면 수행이 무너진다는 이야기다”

아닙니다.

경의 원인은,

# **수행자가 감각문을 지키지 않고**
# **대상을 붙잡아**
# **바르지 않은 사유로 욕탐을 키운 것**

입니다.

---

## “오개가 생기면 수행 실패다”

제704~711경은 오개가 **조건에 따라 생기고 조건에 따라 줄어든다**고 설명합니다.

오개가 나타났다는 사실보다,

# **무슨 조건이 키우고 무엇이 줄이는지 아는 것**

이 중요합니다.

# 호킨스 박사님 언어로 다시 보기

아래는 『잡아함경』 제26권의 직접 표현이 아니라, 같은 내용을 호킨스 박사님의 개념 체계로 다시 비춰보는 비교 해설입니다.

## 연결되는 지점

제654경의 들보 비유는,

# **신뢰·의지·주의·집중이 지혜에 의해 방향을 얻는다**

는 점에서,
단순한 의지의 강도보다 **맥락을 정확히 보는 것**이 중요하다는 언어와 제한적으로 비교할 수 있습니다.

제661경의 ‘헤아림의 힘’은,

# **행동하기 전에 그 의도와 결과를 알아차리는 능력**

이라는 점에서,
자기 반응을 자동 실행하지 않고 관찰하는 태도와 비교할 수 있습니다.

제704~711경은,

# **어떤 마음 상태도 원인 없이 생기지 않으며**
# **주의와 사유의 방향에 따라 강화되거나 약해진다**

는 조건 구조를 보여 줍니다.

## 중요한 차이

그러나 다음처럼 동일시하지 않습니다.

### 오근 = 의식수준 다섯 단계
아닙니다.

### 혜근 = Hawkins의 knowingness
동일하지 않습니다.

### 칠각지 = 에너지 상태의 상승 단계
아닙니다.

### 여래십력 = 비선형장의 능력 목록
아닙니다.

### 연기적 조건성 = 비선형성
기계적으로 같은 말이 아닙니다.

초기불교의 직접 구조는,

# **조건을 알고**
# **오개를 줄이고**
# **칠각지를 닦으며**
# **사성제를 사실대로 알아**
# **탐욕·무명을 끊는 것**

입니다.

# 제26권 최종 정리

『잡아함경』 제26권은
70경이나 되지만,
사실 하나의 질문을 여러 각도에서 반복합니다.

# **“수행이 실제 힘이 되려면 무엇이 필요한가?”**

첫 답은 오근입니다.

# **신뢰**
# **정진**
# **마음챙김**
# **삼매**
# **지혜**

입니다.

그러나 이 다섯을 단순히 나란히 놓지 않습니다.

제654경은,

# **지혜가 들보**

라고 합니다.

왜냐하면 신뢰도,
정진도,
마음챙김도,
삼매도
무엇이 괴로움의 원인이고 무엇이 괴로움의 소멸인지 모르면
다른 방향으로 갈 수 있기 때문입니다.

그래서 혜근은,

# **사성제를 사실대로 아는 지혜**

입니다.

하지만 지혜만 있으면 된다는 말도 아닙니다.

신뢰가 발을 내딛게 하고,
정진이 계속 걷게 하며,
마음챙김이 길을 놓치지 않게 하고,
삼매가 마음을 안정시키며,
지혜가 그 길의 방향을 알아봅니다.

이 능력이 굳어지면,

# **오력**

이 됩니다.

제661경부터는 수행의 힘이 더 현실적인 삶으로 내려옵니다.

행동하기 전에,

> **“이 행동을 하면 지금과 나중에 어떤 결과가 생길까?”**

를 헤아립니다.

몸·말·마음의 악행을
후회·비난·나쁜 결과와 연결해 미리 봅니다.

그렇게 충동을 멈추고
선행을 선택합니다.

그리고 자기 수행만이 아니라,
사람을 함께 붙드는 **사섭**도 나옵니다.

# **보시**
# **좋은 말**
# **이익되는 행동**
# **함께함**

입니다.

즉 불교의 ‘힘’은
다른 사람을 지배하는 힘보다,

# **자기 번뇌에 끌리지 않고**
# **남에게 이익이 되게 관계를 만드는 힘**

에 가깝습니다.

제684경에서는 큰 질문이 나옵니다.

> **“부처와 아라한은 둘 다 해탈했다면 무엇이 다른가?”**

경의 답은,
아라한의 해탈을 낮추는 것이 아닙니다.

둘 다 오온에서 이욕하고 해탈합니다.

다만 부처는,

# **누구에게 듣지 않고 길을 먼저 깨닫고**
# **그 길을 정리해**
# **다른 사람에게 설명하고**
# **수행 공동체를 이끄는 사람**

입니다.

그래서 여래십력도
단순한 초능력 목록으로만 읽으면 놓치는 것이 많습니다.

# **무엇이 가능하고**
# **어떤 원인이 어떤 결과로 가고**
# **사람마다 근기가 어떻게 다르고**
# **어떤 길이 어디에 도달하는지**

아는 힘이 중심입니다.

마지막 제704~711경에서는
이 모든 것이 아주 실용적인 조건 구조로 압축됩니다.

바르지 않은 사유를 하면,

# **오개가 커집니다.**

탐욕,
성냄,
졸림,
들뜸과 후회,
의심입니다.

오개가 커지면,

# **마음이 덮이고**
# **지혜가 약해지며**
# **깨달음의 요소가 자라지 않습니다.**

반대로 바른 사유를 하고
정법에 귀 기울이면,

# **오개는 줄고**
# **칠각지가 자랍니다.**

마음챙김,
법의 조사,
정진,
기쁨,
가라앉음,
삼매,
평형입니다.

그리고 마지막 제711경은,
원인 없는 번뇌·청정론을 정면으로 부정합니다.

# **번뇌에도 원인이 있습니다.**
# **청정에도 원인이 있습니다.**

이것이 제26권의 가장 중요한 결론입니다.

# **수행은 타고난 성격이나 운이 아니라 조건을 바꾸는 일입니다.**

신뢰를 키우고,
정진하고,
마음챙김하고,
삼매를 닦고,
지혜롭게 봅니다.

바르지 않은 사유를 줄이고,
오개를 약화시키며,
칠각지를 키웁니다.

그렇게,

# **괴로움을 계속 만드는 조건은 줄이고**
# **청정과 해탈을 만드는 조건은 키우는 것**

이 제26권이 보여 주는 수행입니다.

---

# 제26권을 한 문장으로

# **『잡아함경』 제26권은 신뢰·정진·마음챙김·삼매·지혜가 오근에서 오력으로 성숙하고 지혜가 들보처럼 전체 수행의 방향을 붙든다고 설명한 뒤, 행동의 결과를 헤아리는 힘·사섭·참괴 같은 윤리적 힘과 여래가 길을 먼저 발견해 가르치는 지혜력을 펼쳐 보이며, 마지막에는 바르지 않은 사유가 오개를 키우고 바른 사유와 정법 청취가 칠각지를 키운다는 조건 구조를 통해 ‘번뇌와 청정 모두 원인과 조건이 있다’는 결론에 이른다.**

- 제646~658경의 오근을 각각 사불괴정·사정단·사념처·사선·사성제와 연결하고 혜근의 들보 역할을 보존
- 제659경의 `發菩提心`을 현존 한역 표현으로 보존하되 후대 대승 보리심 체계 전체와 자동 동일시하지 않음
- 제661경의 `數力`을 행동의 결과를 헤아려 악행을 멈추는 윤리적 숙고의 힘으로 설명
- 제667~669경의 사섭을 지배 기술이 아니라 보시·애어·이익행·동리의 관계적 수행으로 설명
- 제677~683경의 참괴를 자기혐오가 아니라 악행을 부끄러워하고 꺼리는 윤리적 힘으로 설명
- 제684경에서 여래와 아라한 모두 오온에서 이욕·해탈한다는 공통점을 지우지 않고, 여래가 길을 먼저 스스로 발견·설명·지도하는 차이를 중심으로 설명
- 여래십력의 숙명·천안·재생 전승을 원문 요소로 보존하되 현대의 타인에 대한 전생 업 추정의 근거로 사용하지 않음
- 제692~693·699~700경의 여성에 대한 성별 고정관념을 현존 고대 목록으로 보존하되 현대 여성의 본성에 대한 보편 명제로 일반화하지 않음
- 제694경은 ‘여덟 힘’이라고 시작하지만 현존 한역이 여덟 항목을 명료하게 번호화하지 않으므로 임의로 항목을 복원하지 않음
- 제708경의 성적 욕망 장면을 여성 존재 자체의 문제로 돌리지 않고 수행자의 감각수호·부정사유·욕탐 증장의 문제로 설명
- 제704~711경의 오개와 칠각지를 마음의 조건적 증감 구조로 설명
- 제710경의 마음해탈·혜해탈을 탐욕과 무명의 소멸이라는 현존 문맥에서 설명
- 제711경의 핵심을 ‘번뇌와 청정 모두 원인·조건이 있다’는 구조로 유지
- 평행경 정보는 프로젝트 내부 SuttaCentral 평행전승 검색색인을 보조적으로만 사용
- 평행전승의 문장을 한역의 난해·압축 부분에 자동으로 채워 넣지 않음
